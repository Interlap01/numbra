# Preview stand-ins — INCOMPLETE, and probably not the right route

Everything in this directory is MobAI-preview-only. None of it ships, and no
file under `Sources/` outside `.mobai/` was changed to make it work.

## State: the preview does not run

The engine setup is complete (`mobai-dev setup --framework swiftui` reports
`ready: true`, `renderer: paint host (full fidelity)`). Bringing a screen up is
what does not work, and the reason is structural rather than a missing adapter:

- The engine ships `CGImage` and `CGContext` as sealed, empty placeholder
  classes — no pixels, no drawing, and `internal` initializers, so project code
  cannot construct one. Numbra is a CoreGraphics app: PBNSamples draws every
  sample scene into a CGContext, PBNEngine reads pixels back out of a CGImage,
  and thumbnails go CGImage → UIImage → SwiftUI.
- `Sources/Canvas/PaintCanvasView.swift` needs `@objc` selectors and
  `UIAccessibilityElement`; the engine compiles on Linux with no Objective-C
  runtime and refuses the file.
- One line still does not compile: `ProgressView().controlSize(.large)` in
  OnboardingView.swift comes back `ambiguous use of 'large'`.

Even with that last line fixed, what would render is Numbra's layout and
typography with **blank artwork throughout** and a placeholder where the paint
canvas belongs, because nothing behind them can draw. That is a poor likeness
of a paint-by-numbers app.

**Use a simulator or a device instead**: `.github/workflows/ios-sim.yml`, the
`building-ios-in-cloud` skill, or `mobai-up` for a real iPhone. Those run real
CoreGraphics and real UIKit.

## What is here

| file | origin |
| --- | --- |
| `mocks/AVFoundation.swift`, `mocks/PhotosUI.swift`, `mocks/Photos.swift` | MobAI adapter catalogue, unmodified |
| `mocks/UIKit.swift` | generated by the engine from Apple SDK IR |
| `mocks/ImageIO.swift` | written here — PBNEngine's `import ImageIO` is unused, this unblocks it |
| `mocks/QuartzCore.swift` | written here — a real monotonic clock for `CACurrentMediaTime()` |
| `sources/CoreGraphicsStandIn.swift` | written here — CGImage/CGContext/CGGradient/CGImageAlphaInfo and UIImage bridging. **Shape only: every drawing call is a no-op.** |
| `sources/SwiftUIStandIn.swift` | written here — SwiftUI `Canvas` and GraphicsContext members the engine lacks. Draws nothing. |
| `sources/CanvasStandIn.swift` | written here — stands in for the two files `excluded.txt` keeps out. **Renders a labelled placeholder, not the real canvas.** |

The three `sources/` files are fabrications: they exist so the app compiles,
and they do not reproduce app behaviour. Do not read a preview built on them
as evidence about rendering.
